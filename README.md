# РКО/ПАРТНЁР — лендинг партнёрской программы РКО

Одностраничник под трафик из TikTok: человек за 5 секунд понимает предложение,
за 30 секунд выбирает путь и пишет в Telegram. Без сборки, без фреймворков,
без внешних картинок — чистые HTML + CSS + JS.

## Как открыть

Самый простой способ — открыть `index.html` двойным кликом.

Для проверки в браузере как на сайте:

```bash
cd rko-landing
python3 -m http.server 8787
# http://127.0.0.1:8787
```

Режим для скриншотов без анимаций: `http://127.0.0.1:8787/?static=1`.
Прямые ссылки на пути: `#earn` (разовый заработок), `#team` (команда).

## Файлы

```
rko-landing/
  index.html            разметка, мета, инлайн-SVG иконки
  assets/style.css      дизайн, токены, адаптив, анимации
  assets/config.js      ВСЕ цифры: банки, суммы, слайдеры, telegram
  assets/app.js         логика: пути, калькуляторы, анимации, аккордеон
  README.md
```

## Где править цифры

Всё содержимое сайта читается из `assets/config.js` (`window.RKO`).
В HTML и JS цифры не дублируются.

| Ключ | Что делает | Пример |
|---|---|---|
| `telegram` | контакт для всех кнопок, без `@` | `'Sxp21'` |
| `packages` | сумма за пакет по числу счетов | `3 → 15000, 4 → 17500, 5 → 20000` |
| `banks` | банки, тип счёта и вилка выплаты за счёт | 5 строк `{name, account, min, max}` |
| `team.bankPerAccount` | сколько в среднем платит банк за один счёт, ₽ | `7000` |
| `team.split` | фиксированная раскидка за счёт | `{owner: 0.2, lead: 0.3, worker: 0.5}` |
| `team.chartMonths` | горизонт графика «доход за 6 месяцев» | `6` |
| `team.calc.*` | диапазоны и стартовые значения слайдеров | `leads {min:2, max:40, value:12}`, `accounts {min:1, max:5, value:3}` |

## Формула калькулятора (путь 02)

Два ползунка: **лидов в месяц** и **счетов откроет один лид**. Раскидка за каждый
счёт фиксированная: 20% — организатору, 30% — лиду, 50% — работнику из команды.

При стартовых значениях (лиды 12, счетов с лида 3, банк платит 7 000 ₽ за счёт):

- выплата работнику с одного счёта = 7 000 × 50% → **3 500 ₽**
- счетов в месяц = 12 × 3 → **36**
- с одного лида = 3 × 3 500 → **10 500 ₽**
- итого в месяц = 36 × 3 500 → **126 000 ₽** · за год → **1 512 000 ₽**

Проверка ориентира: 5 счетов × 3 500 ₽ = **17 500 ₽** — в вилке «15–20 000 ₽».
Все цифры правятся в `assets/config.js` (`team.bankPerAccount`, `team.split`, `team.calc`).

## Как залить

Это статический сайт — подходит любой хостинг:

- GitHub Pages / Vercel / Netlify: загрузи папку `rko-landing` целиком, стартовый файл `index.html`;
- обычный хостинг: залей файлы в `public_html`.

Смена контакта в одной строке: `assets/config.js` → `telegram`.

## Что осталось на потом

- Аналитика (Metrika) — добавить счётчик в `<head>`;
- Свой домен и редирект с короткой ссылки для кнопок;
- Форма/заявка вместо (или в дополнение к) Telegram — сейчас весь контакт идёт в личку;
- Фотографии владельца или видео-контент в секции «Калькулятор/Команда» (по ТЗ — ни картинок, ни аватаров);
- A/B тест сегмента «3/4/5 счетов» и текстов первого экрана.
